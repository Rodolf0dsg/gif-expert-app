# Gif Expert App v2 — React + TypeScript + Vite

Segunda versión del proyecto **Gif Expert App**, reescrita con **TypeScript** y **SWC** para mayor rendimiento y escalabilidad.

Esta versión incluye:
- Búsqueda de GIFs con integración a Giphy API
- Loaders visuales optimizados
- Sistema de caché para mejorar la experiencia de usuario
- Arquitectura modular con tipado estricto
